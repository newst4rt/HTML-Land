## Introduction

### The Beginning

*The motivation behind building this project was the wide range of HTML elements that every web developer should be familiar with. HTML-Land aims to help learners gain a deeper understanding of these elements by providing interactive, rendered examples in the browser.*

### How it works

*HTML-Land has been built with Vite and uses React under the hood. Most of the code is written in JavaScript and JSX, while the HTML examples and their explanations have been generated with the assistance of AI. The project also relies on various third-party libraries to enhance the user experience — more information, see here.*

### Why HTML-Land

*The platform is an interactive educational platform aims to help learner understanding elements of HTML more easily. Its integrated browser allows user to experiment with HTML and CSS within the interface and the multitasking environment is designed to enhance the learning experience by providing an intuitive and flexible workspace.*

*Also, rendered examples give learners a clearer understanding of how HTML elements behave, while selecting from predefined HTML attributes makes it easier to explore the capabilities and functionality of individual HTML tags.*   


## Get Started

### Installation

```bash
git clone https://github.com/newst4rt/HTML-Land.git
cd HTML-Land
npm install
```

### Initialization

```bash
npm run dev
```
*Once the server has started, open the local URL displayed in your terminal (usually http://localhost:5173).*


### Security Risk

*The platform includes a simulated browser. The browser is not sandboxed and can caused to security issues by hosting and sharing it for the public.* **Please be patient by sharing it with others !**
