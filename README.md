## Introduction

### The Beginning

*The motivation behind building this project was the limited range of HTML elements that every web developer should be familiar with. Reading documentation can sometimes be annoying and HTML is a very easy-to-understand language in web development. Even a documentation is sometimes not necessary to understand how an element in HTML works. HTML-Land shows a different way of learning by providing interactive, rendered examples in the browser with the option to choose between the different available attributes.*


### How it works

*HTML-Land uses React under the hood. Most of the code is written in JavaScript and JSX, while the HTML examples, explanations and pictures have been generated with the assistance of AI. The project also relies on various third-party libraries to enhance the user experience — more information, see [here](/THIRD-PARTY-NOTICES.md).*

### Why HTML-Land

*The platform is an interactive educational platform designed to help learners understand elements of HTML more easily. Its integrated browser allows users to experiment with HTML and CSS, while its browser-like interface is designed to enhance the learning experience by providing an intuitive and flexible workspace.*

*Rendered examples provide clarity when choosing the right element, while selecting from predefined HTML attributes makes it easier to explore the capabilities and functionality of each individual HTML tag.*   


## Get Started

### Installation

```bash
git clone https://github.com/newst4rt/HTML-Land.git
cd HTML-Land
npm install
```

### Initialization

```bash
npm run dev
```
*Once the server has started, open the local URL displayed in your terminal (usually http://localhost:5173).*


### Security Risk

*The platform includes a simulated browser. The browser is not sandboxed and it may cause security issues when hosting or sharing it with others.*
